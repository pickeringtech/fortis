Agent mode: Rule index (LR D)

Appendix D: Rule index#

Human mode. Agent mode: Rule index. Source of truth: the rule tables at the end of each LR section, and LR D.

Every normative rule of the core has an ID of the form LANG-<section>-<nn>, and each LR section ends with a table of its rules and the evidence that tests them (LR 0). This appendix lists every rule in one place, says in a line what it means, and points to the chapter that explains it. The one-line summaries are paraphrases; the rule text in the LR is the rule.
