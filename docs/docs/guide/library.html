Agent mode: Core runtime inventory (LR 15)

The core library#

Human mode. Agent mode: Core library, by declaration. Generated by conformance/tools/libref.py from the declarations of library/fortis; do not edit. Source of truth: LR 15.

Preview: the core runtime inventory (LR 15) arrives in v0.4.

This is the reference for the standard library that ships with the compiler: every type and function of the core package fortis, with its signature, what it promises and the effects it has. It is not a tutorial; the chapters of this guide teach the language, and this page is where you look an operation up. Nothing here is written by hand: each entry is the library's own declaration and the documentation comment above it, so the page cannot say something the library does not do. The same facts, as tables for tools, are in the agent-mode page.

How to read an entry#

The library is one package, fortis, made of seven modules. Each section below is a module. fortis.prelude is imported into every module for you; the others you import by name (LR 4.3). Under a module come its types, each with its operations, and then its free functions.

An entry is the operation's signature followed by what it promises. Read the signature the way you read your own: self is the value the operation is called on, a word before func such as pure or try is a claim the compiler checks (LR 11.2), and from self says the result is a loan of the receiver, so it cannot outlive it (LR 7.6). Most operations are trusted: the toolchain implements them, and the sentence under the signature is the contract a reviewer signed off (LR 11.3). A cost such as O(n) is the bound the contract promises.

Effects tell you what calling the operation does beyond computing its result, and what your own function inherits by calling it (LR 11.1):

  • pure: written before the effects when the signature claims it: the operation reads nothing from outside its arguments and writes nothing (LR 11.2). The effects after it are what a pure operation may still do, such as allocate or fail.
  • noalloc: written before the effects when the signature claims it: the operation promises not to allocate (LR 11.4).
  • none: an operation that does not claim pure and has no effect to declare.
  • alloc: it allocates; it cannot be called from noalloc code (LR 11.4).
  • fail: it is declared try: it can fail, and the caller must handle the outcome (LR 10.1).
  • suspend: it is async and can wait (LR 12.3).
  • recovers: it discards a failure it handled (LR 10.4).
  • block: it blocks the calling thread (LR 11.1).
  • io: it reaches the outside world through an authority (LR 11.6).
  • mutate: it writes storage that tasks share (LR 11.1).
  • nondet: its result can differ between runs with the same arguments (LR 11.1).
  • writes self: it changes the value it is called on (editable self).

fortis.prelude#

You never import this module; every module has it already (LR 4.3). It holds the types you use in every program: the integers and floats, String and StringView, lists, maps and sets, Outcome and Failure, the concurrency types, and the built-in interfaces such as Equatable and Displayable. The everyday text operations (trim, split, find, replace and the rest) are members of String and StringView, so they need no import either. (LR 4.3, LR 6.2, LR 6.10).

class Int#

  • pure try func add(a: Int, b: Int) Int. Checked 64-bit two's-complement addition; fails numeric.overflow outside [-2^63, 2^63-1]; O(1), no allocation. Effects: pure; fail.
  • pure try func sub(a: Int, b: Int) Int. Checked subtraction; fails numeric.overflow; O(1), no allocation. Effects: pure; fail.
  • pure try func mul(a: Int, b: Int) Int. Checked multiplication; fails numeric.overflow; O(1), no allocation. Effects: pure; fail.
  • pure try func div(a: Int, b: Int) Int. Truncating division; fails numeric.divide_by_zero when b = 0 and numeric.overflow for -2^63 / -1; O(1). Effects: pure; fail.
  • pure try func rem(a: Int, b: Int) Int. Remainder with the sign of a; fails numeric.divide_by_zero when b = 0; O(1). Effects: pure; fail.
  • pure try func shiftLeft(a: Int, bits: Int) Int. A * 2^bits; fails numeric.shift_range unless 0 <= bits < 64 and numeric.overflow when the result is out of range; O(1). Effects: pure; fail.
  • pure func wrappingAdd(a: Int, b: Int) Int. Addition modulo 2^64 into [-2^63, 2^63-1]; total; O(1). Effects: pure.
  • pure func wrappingSub(a: Int, b: Int) Int. Subtraction modulo 2^64; total; O(1). Effects: pure.
  • pure func wrappingMul(a: Int, b: Int) Int. Multiplication modulo 2^64; total; O(1). Effects: pure.
  • pure func saturatingAdd(a: Int, b: Int) Int. Addition clamped to [-2^63, 2^63-1]; total; O(1). Effects: pure.
  • pure func saturatingSub(a: Int, b: Int) Int. Subtraction clamped to [-2^63, 2^63-1]; total; O(1). Effects: pure.
  • pure func saturatingMul(a: Int, b: Int) Int. Multiplication clamped to [-2^63, 2^63-1]; total; O(1). Effects: pure.
  • pure try func validate(value: Int) Int. The value when it lies in the refinement of the receiver type; fails refinement.out_of_range otherwise; O(1). Effects: pure; fail.

class Decimal#

  • pure try func add(a: Decimal, b: Decimal) Decimal. The sum at the larger operand scale, rounded half to even when it needs more than 96 coefficient bits; fails numeric.overflow when the integer part does not fit (6.4); O(digits). Effects: pure; fail.
  • pure try func sub(a: Decimal, b: Decimal) Decimal. The difference at the larger operand scale, rounded half to even when needed; fails numeric.overflow (6.4); O(digits). Effects: pure; fail.
  • pure try func mul(a: Decimal, b: Decimal) Decimal. The product at the sum of the scales, rounded half to even above 28 fractional digits or 96 coefficient bits; fails numeric.overflow (6.4); O(digits^2). Effects: pure; fail.
  • pure try func div(a: Decimal, b: Decimal) Decimal. The quotient at the largest scale that fits, rounded half to even; fails numeric.divide_by_zero and numeric.overflow (6.4); O(digits^2). Effects: pure; fail.
  • pure try func rem(a: Decimal, b: Decimal) Decimal. The remainder with the sign of the dividend at the larger operand scale; fails numeric.divide_by_zero (6.4); O(digits^2). Effects: pure; fail.
  • pure func round(value: Decimal, scale: Int<0..28>, mode: RoundingMode) Decimal. Value rounded to scale by mode; total; O(digits). Effects: pure.
  • pure try func fromFloat(x: Float, scale: Int<0..28>, mode: RoundingMode) Decimal. The binary value of x rounded to scale by mode; fails numeric.overflow for a non-finite x or an integer part that does not fit (6.4); O(digits). Effects: pure; fail.
  • pure func scale(self) Int<0..28>. The number of fractional digits; O(1). Effects: pure.

class String#

  • pure func from(text: StringView) String. An owned copy of the view; allocates; O(n) in bytes. Effects: pure; alloc.

  • pure func byteCount(self) Int. The UTF-8 length in bytes; O(1). Effects: pure.

  • pure func find(self, needle: StringView) Int<0..>?. The scalar offset (the unit of slice and scalarAt) of the first occurrence of needle, null when it does not occur; an empty needle occurs at 0; no allocation; at most O(n * m) in bytes for a text of n bytes and a needle of m. Effects: pure.
  • pure func contains(self, needle: StringView) Bool. True exactly when find(needle) is present: an empty needle is contained in every text. Effects: pure.
  • pure func startsWith(self, prefix: StringView) Bool. True exactly when the text begins with prefix (an empty prefix always does); no allocation; O(m) in bytes for a prefix of m. Effects: pure.
  • pure func endsWith(self, suffix: StringView) Bool. True exactly when the text ends with suffix (an empty suffix always does); no allocation; O(m) in bytes for a suffix of m. Effects: pure.
  • pure func split(self, separator: StringView) List[String]. The pieces between the non-overlapping occurrences of separator, found left to right, as owned strings; a separator at either end gives an empty piece there, a text without the separator gives one piece (itself), and an empty separator occurs nowhere, so it gives one piece; allocates; O(n) in bytes. Effects: pure; alloc.
  • pure func lines(self) List[String]. The lines of the text as owned strings, each ended by a line feed or by a carriage return and a line feed (neither stays in the line); the text after the last terminator is a line only when it is not empty, so "" has no lines and "a\n" has one; a carriage return not before a line feed stays in the line; allocates; O(n) in bytes. Effects: pure; alloc.
  • pure func replace(self, old: StringView, new: StringView) String. A copy of the text with every non-overlapping occurrence of old, found left to right, replaced by new; an empty old occurs nowhere, so the copy is unchanged; allocates; O(n) in bytes plus the find cost. Effects: pure; alloc.
  • pure func asciiUpper(self) String. A copy with the ASCII letters a-z mapped to A-Z and every other scalar unchanged (not Unicode case mapping: that depends on the Unicode version and the language, and changes lengths); allocates; O(n) in bytes. Effects: pure; alloc.
  • pure func asciiLower(self) String. A copy with the ASCII letters A-Z mapped to a-z and every other scalar unchanged (as asciiUpper); allocates; O(n) in bytes. Effects: pure; alloc.
  • pure func repeat(self, times: Int<0..>) String. The text written times in a row: "" when times is 0 or the text is empty; allocates; O(times * n) in bytes. Effects: pure; alloc.
  • pure func join(parts: ListView[String], separator: StringView) String. The parts in order with separator between neighbours: "" for no parts and the part itself for one; allocates; O(total length). Effects: pure; alloc.

  • pure func filter(self, keep: pure fn(T) Bool) List[T] where T implements Copyable Effects: pure; alloc.

  • try func tryEach(self, visit: editable fn mut(T) Outcome[Void]). As each, stopping at the first failure of the callback and returning it (X-479); O(n) plus the callback per element. Effects: fail.
  • pure try func tryMap[U](self, f: pure fn(T) Outcome[U]) List[U]. As map, stopping at the first failure of the callback and returning it, with the new list dropped (X-479); allocates; O(n) plus the callback per element U must be non-linear: failure drops earlier results (10.7, E-OBL-003). (E-OBL-003: LR 5.3). Effects: pure; alloc, fail.
  • pure func fold[A](self, initial: owned A, step: pure fn(A, T) A) A. Step gets a read loan of the accumulator and an element, once per element in order, and returns the next accumulator (X-479); O(n) plus the callback per element. Effects: pure.
  • pure try func tryFold[A](self, initial: owned A, step: pure fn(A, T) Outcome[A]) A. As fold, stopping at the first failure of step and returning it (X-479); O(n) plus the callback per element. Effects: pure; fail.
  • pure func any(self, holds: pure fn(T) Bool) Bool. Whether holds is true for some element; stops at the first one that passes (X-479); O(n) plus the callback. Effects: pure.
  • pure func all(self, holds: pure fn(T) Bool) Bool. Whether holds is true for every element; stops at the first one that fails (X-479); O(n) plus the callback. Effects: pure.
  • pure func find(self, holds: pure fn(T) Bool) (alias T from self)?. A read loan of the first element holds is true for, null when none does (X-479); O(n) plus the callback. Effects: pure.
  • pure func indexWhere(self, holds: pure fn(T) Bool) Int?. The index of the first element holds is true for, null when none does (X-479); O(n) plus the callback. Effects: pure.
  • pure func contains(self, target: T) Bool where T implements Equatable. Whether some element equals target (X-479); O(n). Effects: pure.
  • pure func enumerate(self) List[(Int, T)] where T implements Copyable. Each element copied with its index, in order (X-479); allocates; O(n). Effects: pure; alloc.
  • pure func zip[U](self, other: ListView[U]) List[(T, U)] where T implements Copyable, U implements Copyable. Pairs of copies of the elements at the same index of self and other, as many as the shorter has (X-479); allocates; O(min(n, m)). Effects: pure; alloc.
  • pure func take(self, n: Int) List[T] where T implements Copyable. Copies of the first n elements, all of them when n is at least count(), none when n is 0 or less (X-479); allocates; O(min(n, count)). Effects: pure; alloc.
  • pure func skip(self, n: Int) List[T] where T implements Copyable. Copies of the elements after the first n, none when n is at least count(), all when n is 0 or less (X-479); allocates; O(count). Effects: pure; alloc.
  • pure func flatMap[U](self, f: pure fn(T) List[U]) List[U] where U: linear. The lists f returns for each element, joined in order (X-479); allocates; O(n) plus the sizes of the lists plus the callback per element. Effects: pure; alloc.
  • pure func chunked(self, size: Int<1..>) List[List[T]] where T implements Copyable. Copies of the elements in lists of size elements, the last one shorter when size does not divide count() (X-479); allocates; O(n). Effects: pure; alloc.
  • pure func sortedBy[K](self, key: pure fn(T) K) List[T] where T implements Copyable, K implements Comparable. Copies of the elements ordered by key(element), smaller keys first, elements with equal keys in their original order (a stable merge sort over indexes); key is called once per element (X-479); allocates; O(n log n) comparisons plus n callbacks. Effects: pure; alloc.
  • pure func groupBy[K](self, key: pure fn(T) K) Map[K, List[T]] where T implements Copyable, K implements Copyable, K implements Hashable, K implements Equatable. Copies of the elements gathered by key(element) into a Map from each key to its elements in their original order; the keys are in the order they first appear (X-479); allocates; expected O(n) plus n callbacks. Effects: pure; alloc.
  • pure func iterate(self) ListCursor[T] from self. A cursor over read loans of the elements in order; O(1) to create, O(1) per step. Effects: pure.
  • func consumeEach(owned self, visit: fn mut(owned T) Void). Consumes the list (10.7): no early exit, so no element is left unvisited; an empty list makes no calls intrinsic: calls visit once per element in order, transferring each element out; O(n) plus the callback per element. Effects: none.
