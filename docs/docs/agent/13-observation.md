# Observation schemas and statements (LR 13)

<!-- covers: LR 13 -->
*Agent mode. Human mode: [Observation](../guide/13-observation.md). Source of truth: LR 13.*

> Preview: observation schemas, `capture` and `record` (LR 13) arrive in v0.5. Log statements, `log.info`, `log.warn` and `log.error` (LR 13), are in v0.0.2.

## Rules

| Rule | Statement | LR |
|---|---|---|
| LANG-13-01 | `capture field = e` snapshots `e` at the statement, copying it into the activation's frame; `e` is pure, infallible, non-suspending and of the field's declared type; it takes a read loan for the statement only. `record Name(field: v, …)` has the same requirement for its arguments. | LR 13 |
| LANG-13-02 | Each `required: all` field is assigned on every path before every exit; `required: success` / `failure` before every exit of that class; at most one `capture` per field per path; no `capture` in a loop body. Exits include `fail`, `return`, `await` (a cancellation edge) and cancellation. | LR 13 |
| LANG-13-03 | Frame contents are bounded by the schema: a `String` field declares a bound; a longer value is truncated or omitted as the schema declares, and the frame records which. | LR 13 |
| LANG-13-04 | `log.info(m)`, `log.warn(m)` and `log.error(m)` write one `log` record (level, message, function) to the diagnostic plane, standard error, never standard output; `m` is a `StringView`; no capability is needed, and the statement has the `io` effect, so a `pure` function cannot log. `log` is not a keyword: where a binding or declaration named `log` is in scope, `log.info(...)` is an ordinary call. Record a failure with `report e`, not a log; log what is not a failure (X-345, X-147). | LR 13 |

## Declarations and statements

| Form | Meaning | LR |
|---|---|---|
| `observation Name { … }` with one item per line: `version: n` (optional), each `field: T required: all\|success\|failure\|none`, and `encoding: bounded(n)` | schema; `version` defaults to 1; every field type `Encodable` (recursively, as derivation) | LR 13, LR 6.10 |
| `@observe(Name)` above a function head | the core aspect attaching the schema; the frame's fields are the schema's | LR 13, LR 11.8 |
| `capture field = e` | assign the frame field once | LR 13 |
| `record Name(field: v, …)` | emit one event per execution; allowed in loops | LR 13 |
| start, end, duration, outcome class | generated by the compiler; never written in source | LR 13 |
| cancelled before start | a frame marked `not_started`, no captured fields | LR 13 |
| `log.info(m)`, `log.warn(m)`, `log.error(m)` | one `log` record (`level`, `message`, `function`) per execution, to standard error: text on a terminal (`warn: could not take 9 nuts`), a JSON line otherwise; never standard output | LR 13, LR 11.7 |

Effects: observation does not change a function's effect summary; records go to the diagnostic plane, which
feeds nothing back (LR 11.7). A `pure` function may be observed. A log statement is the exception: it has the
`io` effect, like `report`, so a `pure` function cannot log; it needs no capability (LR 13, LR 11.6). Output: the default task reporter writes frames
without field values to standard error; field values leave only through the Telemetry kit, or on the record
stream under the development plan `FORTIS_TELEMETRY=permit-all` (LR 15).

## Diagnostics

| Code | Trigger | Correction | LR |
|---|---|---|---|
| E-OBS-001 | a required field unassigned on an applicable exit (`return`, `fail`, an `await`, the end) | `capture` the field before that exit; for an `await`, before the `await` | LR 13 |
| E-OBS-010 | a second `capture` of one field on one path | keep one `capture`; compute the value first | LR 13 |
| E-OBS-011 | `capture` inside a loop body | capture once after the loop, or use `record` for per-iteration events | LR 13 |
| E-OBS-012 | `capture`/`record` whose expression has an effect; a field the schema lacks; `capture` with no schema attached | bind the fallible or suspending value on its own line and capture the binding; fix the field name; attach `@observe(Schema)` | LR 13 |
| E-TYP-090 | a schema field type that is not `Encodable` (`Secret[T]`, an authority, a loan, a closure, …) | capture an `Encodable` projection, never the secret or resource | LR 13, LR 6.10 |

## Correction patterns

### E-OBS-001: required field missing on a failure exit (LR 13)

```fortis
// reject: E-OBS-001
export error Rejected {
  code: "shop.rejected"
}

observation Payment {
  amount: Int        required: all
  reason: Int        required: failure
}

@observe(Payment)
try func pay(amount: Int<0..10000>) Int {
  capture amount = amount
  if amount == 0 {
    fail Rejected()          // reject: E-OBS-001
  }
  return amount
}

test "pay" {
  expect pay(5) == 5
}
```

```fortis
// accept
export error Rejected {
  code: "shop.rejected"
}

observation Payment {
  amount: Int        required: all
  reason: Int        required: failure
}

@observe(Payment)
try func pay(amount: Int<0..10000>) Int {
  capture amount = amount
  if amount == 0 {
    capture reason = 1
    fail Rejected()
  }
  return amount
}

test "pay" {
  expect pay(5) == 5
}
```

### E-OBS-001: required field after an `await` (LR 13, LR 12.4)

```fortis
// reject: E-OBS-001
async func pause() {
}

observation Wait {
  tier: Int        required: all
}

@observe(Wait)
async func slow(tier: Int) Int {
  await pause()              // reject: E-OBS-001
  capture tier = tier
  return tier
}

test "slow" {
  expect true
}
```

```fortis
// accept
import fortis.host { Clock, Console }

observation Wait {
  tier: Int        required: all
}

@observe(Wait)
async func slow(clock: Clock, tier: Int) Int {
  capture tier = tier
  await clock.sleep(5ms)
  return tier
}

async func main(clock: Clock, console: Console) {
  let t = await slow(clock, 2)
  console.print("tier ${t}")
}
```

```output
tier 2
```

### E-OBS-010: captured twice (LR 13)

```fortis
// reject: E-OBS-010
observation Trace {
  tier: Int        required: all
}

@observe(Trace)
pure func process(n: Int<0..100>) Int {
  capture tier = n
  capture tier = n + 1       // reject: E-OBS-010
  return n
}

test "process" {
  expect process(1) == 1
}
```

```fortis
// accept
observation Trace {
  tier: Int        required: all
}

@observe(Trace)
pure func process(n: Int<0..100>) Int {
  let tier = n + 1
  capture tier = tier
  return n
}

test "process" {
  expect process(1) == 1
}
```

### E-OBS-011: capture in a loop (LR 13)

```fortis
// reject: E-OBS-011
observation Batch {
  last: Int        required: none
}

@observe(Batch)
pure func sum(items: List[Int<0..100>]) Int {
  let mut total = 0
  for item in items {
    capture last = item      // reject: E-OBS-011
    total = Int.saturatingAdd(total, item)
  }
  return total
}

test "sum" {
  expect sum(List.of(1, 2)) == 3
}
```

```fortis
// accept
observation Batch {
  count: Int        required: all
}

observation Item {
  value: Int        required: all
}

@observe(Batch)
pure func sum(items: List[Int<0..100>]) Int {
  capture count = items.count()
  let mut total = 0
  for item in items {
    record Item(value: item)
    total = Int.saturatingAdd(total, item)
  }
  return total
}

test "sum" {
  expect sum(List.of(1, 2)) == 3
}
```

### E-OBS-012: an effectful capture expression (LR 13)

```fortis
// reject: E-OBS-012
export error Odd {
  code: "demo.odd"
}

pure try func half(n: Int<0..100>) Int {
  if n % 2 == 1 {
    fail Odd()
  }
  return n / 2
}

observation Trace {
  half: Int        required: none
}

@observe(Trace)
pure try func process(n: Int<0..100>) Int {
  capture half = half(n) or fail     // reject: E-OBS-012
  return n
}

test "process" {
  expect process(4) == 4
}
```

```fortis
// accept
export error Odd {
  code: "demo.odd"
}

pure try func half(n: Int<0..100>) Int {
  if n % 2 == 1 {
    fail Odd()
  }
  return n / 2
}

observation Trace {
  half: Int        required: none
}

@observe(Trace)
pure try func process(n: Int<0..100>) Int {
  let h = half(n) or fail
  capture half = h
  return n
}

test "process" {
  expect process(4) == 4
}
```

### E-TYP-090: a field that is not `Encodable` (LR 13, LR 6.10)

```fortis
// reject: E-TYP-090
import fortis.host { Secret }

observation Login {          // reject: E-TYP-090
  password: Secret[String]   required: all
}

test "nothing" {
  expect true
}
```

```fortis
// accept
observation Login {
  user: String<scalars: 0..64>   required: all
}

@observe(Login)
pure func login(user: String) Int {
  capture user = user
  return 1
}

test "login" {
  expect login("ada") == 1
}
```

## Facts used when writing code

- A `String` field must be bounded: `String<scalars: 0..n>` (LR 13).
- `capture` takes a read loan for its statement and copies; later mutation does not change the frame (LR 13).
- `required: success` fields need not be assigned on failure exits, and the reverse (LR 13).
- A mapped failure (an aspect's `on failure` that returns a value) is a success exit of the outer function; the
  frame is shared by hooks and body (LR 11.8).
- Optimisation preserves required records (trace equivalence); non-required instrumentation may be elided
  (LR 11.7).
- Logs (LR 13) are for what is not a failure: progress, a summary, a fallback taken. A failure is recorded with
  `report e` alone, never logged as well. The program's own output stays `console.print`. `m` is a `StringView`: a literal, an interpolated literal or a `String`.
- `log` is not a keyword: where a binding or declaration named `log` is in scope, `log.info(…)` is an ordinary
  call; `log` used any other way with nothing declared is `E-NAM-001` (LR 13).
- Open defects: no backend supplies the duration (D-28); native writes no `not_started` frame (D-27).
