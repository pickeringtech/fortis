Human mode: Glossary

Glossary (agent mode)#

Agent mode. Human mode: Glossary.

One meaning per term; where a word has two meanings both rows are listed. A bundle of packages is a kit. The Language Reference's glossary is LR E; this page adds the in-language terms.

System#

TermDefinitionSource
packageunit of distribution, versioning, visibility: project.yaml, lockfile, src/; two versions are two packagesLR 4.1
moduleone .ft file under src/; name = path below src/ with . separators; declarations and constants onlyLR 4.2
kitnamed, versioned bundle of packages shipped with the distribution; extends Fortis only by libraries, aspects, heads, embedding bindings, verifiers; never changes core semanticsLR 16
compatibility setthe standard packages at the versions tested together; a standard dependency names the set's versionLR 4.1
toolchain componentdaemon, LSP, SDK generators: tools, not kitsLR 16
backendinterpreter (fortis run, the reference), development VM (fortisc vm), native (fortis build); must agreeLR 1
build modedev (VM), native-dev, release; optimisation and debug settings belong to a modeLR 1
lint levelbaseline (an unused import warns) or strict (it is an error)LR 4.3
target feature setwhich standard modules exist for a target (core, alloc, host, async, web, browser)LR 11.6

Declarations#

TermDefinitionSource
head (declaration head)reserved keyword introducing a schema-validated declaration elaborated to core declarations before type checking; owner: the core (observation, LR 13), developer tooling (explore, LR E), or a kit (the rest)LR 16, LR 13, LR E
elaborationrewriting a head, or a function with aspects, into core declarations before ownership and effect checkingLR 16, LR 11.8
extension slothead block; inject member; aspect application; cases table: the only fourLR 16
raw template regiontext of view { … } in a head body, handed unlexed to the Web UI kitLR 16
aspect@name(args) behaviour around a function: needs, before, after, on failure, metadata; addsLR 11.8
contractnamed conjunction of modifiers, forbidden effects, required or excluded authorities; subtractsLR 11.5
mixinmethods applied with with; requires methods, adds no stateLR 9.6
newtypetype Name = Repr; nominal, private representationLR 6.9
refinementpredicate in <…> on a built-in typeLR 6.3
binding (name)name introduced by let, let mut, a parameter, a pattern or a captureLR 5.1, LR 7.2
binding (embedded language)versioned package giving a language fenced blocks via the embedding protocol; meaning compiler-fixed, checking a verifier (SP-23, not yet in the LR)Embedded languages
verifierstricter-only package: reads the checked program, returns records never code; pure, deterministic, bounded, no capabilityEmbedded languages
