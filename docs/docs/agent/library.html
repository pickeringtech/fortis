Human mode: The core runtime

The core library#

Agent mode. Human mode: The core library. Generated by conformance/tools/libref.py from the declarations of library/fortis and the effect data of reference/library/effects; do not edit. Source of truth: LR 15 for the inventory, and each declaration's own contract.

Preview: the core runtime inventory (LR 15) arrives in v0.4.

Every public declaration of the seven core modules (LR 15): each exported declaration, every member of an exported interface (whose members share its visibility, LR 4.4) and every variant of an exported enum, with its signature as the library declares it, the effects it declares and the contract its documentation comment states. The check counts these against the module sources independently of this page. A trusted operation is implemented by the toolchain, and its comment is its review record (LR 11.3). fortis.prelude is imported into every module; the other modules need an import (LR 4.3). What is not listed here does not exist in Language 1.0's core library; the gaps against the Language Reference are recorded as D-58.

The Effects column is pure or noalloc where the signature claims it, then the effects the operation has, which a caller inherits (LR 11.1, 11.3): alloc, fail (a try function), suspend (async), recovers, block, io (a capability's method, or an operation that takes an authority), mutate, nondet, and writes self (an impure editable self method). none is an impure operation with no effect to declare; a type has none.

class Deque[T] implements Iterable[T, ListCursor[T]]#

front holds the items from the front end, the first item last, so popping the front is its pop; back holds the rest, the last item last. An end that runs dry takes half of the other end's items over, which costs as many moves as the pushes that filled that end, so both ends are amortised O(1) and no item is copied.
