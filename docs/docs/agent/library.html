Human mode: The core runtime

The core library#

Both modes. Generated by conformance/tools/libref.py from the declarations of library/fortis; do not edit. Source of truth: LR 15 for the inventory, and each declaration's own contract.

Preview: the core runtime inventory (LR 15) arrives in v0.4.

Every public declaration of the seven core modules (LR 15): each exported declaration, every member of an exported interface (whose members share its visibility, LR 4.4) and every variant of an exported enum, with its signature as the library declares it and the contract its documentation comment states. The check counts these against the module sources independently of this page. A trusted operation is implemented by the toolchain, and its comment is its review record (LR 11.3). fortis.prelude is imported into every module; the other modules need an import (LR 4.3). What is not listed here does not exist in Language 1.0's core library; the gaps against the Language Reference are recorded as D-58.
