Human mode: The Fortis guide

Diagnostic codes#

Agent mode. Source of truth: the LR section cited in each row; classes and mandatory fields: records.md.

Every diagnostic code the Language Reference names, grouped by class. Rule is the rule ID the toolchain's record carries for the code (most often; where several rules share one code, the record names the one the finding breaks; where the record carries a rule that is not the one the LR states for the code, the row says so, D-57). Pairs is the agent page holding a reject/accept correction pair for the code, or the rules for it. Look a record up by its code, read the cited section, apply the correction, re-check.
