Human mode: Appendix A: Keywords

Keyword inventory (LR A)#

Agent mode. Human mode: Keywords. Source of truth: LR A, LR 3.4.

LANG-03-04Every word below is reserved in every declaration and binding position (variable, parameter, field, type, declaration name), except the name of a method or associated function; after . every word is a member name (memberName). The lexer never reclassifies a keyword.LR 3.4, LR A

Diagnostics#

CodeTriggerCorrectionLR
E-SYN-002a keyword in a declaration or binding position (let match, a field from, a parameter type)rename (pattern, start, kind); a method may keep the keyword nameLR 3.4

Tool behaviour: the checker stops parsing a module at its first E-SYN-002, so fix each one and re-check; the rule itself is LR 3.4.

Correction patterns#

E-SYN-002: keyword as a binding (LR 3.4)#

Fortis
// reject: E-SYN-002
pure func span(start: Int, end: Int) Int {
  let match = end            // reject: E-SYN-002
  return match
}

test "span" {
  expect span(1, 4) == 4
}
Fortis
// accept
pure func span(start: Int, end: Int) Int {
  let last = end
  return last
}

test "span" {
  expect span(1, 4) == 4
}

E-SYN-002: keyword as a field; keep it as a method (LR 3.4, LR A)#

Fortis
// reject: E-SYN-002
class Span {
  export from: Int           // reject: E-SYN-002
}

test "span" {
  expect Span(from: 1).from == 1
}
Fortis
// accept
class Span {
  export start: Int
  export pure func from(start: Int) Span => Span(start)
  export pure func where(self, n: Int) Int => n
}

test "span" {
  let s = Span.from(1)
  expect s.start == 1
  expect s.where(4) == 4
}
