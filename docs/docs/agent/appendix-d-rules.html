Human mode: Appendix D: Rule index

Rule index (LR D)#

Agent mode. Human mode: Rule index. Source of truth: each LR section's rule table; LR D for old IDs.

Every LANG- rule, its section, a condensed statement and the agent page that carries its codes and correction patterns. A diagnostic record's rule field names one of these IDs, or a PROG- or PLAT- ID. The LR rule text is authoritative; the statements here are condensed (LR 0).
