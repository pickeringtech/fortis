Coffee shop: checked domain model#

Agent mode. Human mode: Model a domain. Source of truth: LR 6, LR 8, LR 9, LR 10, LR 11.5 and LR 14.

The complete v0.1.0 showcase and its expected stdout are pinned. The gate checks both checkers and runs main and tests on all three backends. The guide contains the same complete program, also checked by docset.
